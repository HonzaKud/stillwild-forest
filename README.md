# stillwild-forest

An independent nature experience, built with Vite, TypeScript and custom CSS. No backend, accounts or analytics.

## Development

Node.js 22.12+ or 24. Run npm ci, npm run dev. npm run build type-checks and creates dist. npm run preview serves the production build.

## Deployment

Enable GitHub Pages with GitHub Actions. Push main to deploy. Relative asset paths support repository subpaths.

## Media

See MEDIA-SOURCES.md and the public credits page. Generated scenes are explicitly identified, not claimed to be photographs of real locations. Audio is original procedural ambient synthesized locally with Web Audio, no external samples. Audio is off by default. Native scroll, keyboard links, motion pause and reduced-motion support.
